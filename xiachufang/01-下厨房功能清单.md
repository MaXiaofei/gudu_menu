# 下厨房 APP 功能清单(按钮 / 字段级)

> 用于咕嘟小食单竞品借鉴。本文档记录下厨房每个功能模块的**按钮、字段、入口**,方便开发某功能时直接对照参考。
>
> **数据来源**(均为公开信息,未反编译/未爬取 APP 内数据):
> - 应用宝官方应用介绍(主要功能 5 条)
> - 应用宝官方 APP 截图 4 张(首页/视频菜谱/动态流/收藏页)—— 字段原文以此为准
> - 人人都是产品经理两篇深度拆解(woshipm.com/evaluating/2461346.html、3170521.html,V6.8/V7.1 时代)—— 功能架构、菜篮子/会员/课堂/市集细节以此为准
>
> **时效说明**:下厨房版本演进到 V8.8(2026),与 V6.8/V7.1 分析文章时代有差异(如会员体系曾上线又下线、首页改版引发用户争议)。**字段以官方截图为准;架构性功能以分析文章为准;最新版细节差异需自行截图补到 `screenshots/`**。

## 整体导航架构

### 底部主 Tab(5 个,中间为发布 FAB)

| 位置 | Tab | 说明 |
|---|---|---|
| 1 | **首页** | 内容社区,推荐/关注/分类等内容流 |
| 2 | **课堂** | 厨Studio,付费视频课/图文专栏 |
| 3 | **[+] FAB**(红色圆形悬浮) | 发布入口(发布菜谱/发布作品) |
| 4 | **收藏** | 收藏的菜谱,内含菜篮子入口 |
| 5 | **我的** | 个人主页 |

> 注:不同版本底部 Tab 有差异(分析文章时代为「下厨房/市集/课堂/收藏/我」5Tab,官方截图时代为「首页/课堂/+FAB/收藏/我的」)。**市集(电商)在新版似乎从底部 Tab 移除,改为首页顶部"商店"Tab 或独立入口**——以实际版本为准。

### 顶部通用结构(首页)
- 左:**三横线菜单图标**(侧边/个人入口)
- 中:**搜索框**,占位符文字 = `搜索菜谱、课程和食材`
- 右:**铃铛图标**(消息通知)
- 顶部 Tab 条(首页内):`关注` / `推荐` / `减脂` / `商店` / `分类`

## 一、首页 · 内容社区

### 1.1 推荐流(默认首页)
**按钮/字段:**
- 卡片字段:封面图、菜名、作者昵称、右上角「更多(...省略号)」
- 互动(分析文章描述):点赞、评论数
- 顶部:更新提示 icon(关注的用户有视频菜谱更新时,头像提示)

### 1.2 关注流(社交动态)
**按钮/字段(官方截图实测):**
- Tab:`关注` / `推荐` / `减脂` / `商店` / `分类`
- 动态卡片:用户头像 + 用户名(如 `Sunny_Kreglo`、`陈美味`)+ 动态正文 + 配图(N张)
- 卡片右上:「更多(...省略号)」
- 互动按钮:`点赞`(显示数字,如 `121`)+ `评论`(显示数字,如 `1`)
- 发布时间:`1天前`
- 话题标签:`#定格我的早餐瞬间#`

### 1.3 菜谱分类 / 榜单 / 时令(分析文章建议强化的入口)
- **分类**:家常菜/下饭菜/烘焙/零食/素菜等(原有但入口隐蔽)
- **榜单**(用户高度诉求):`本周最受欢迎`、`厨房101`、`月度最佳`、`荣誉殿堂`、`新秀菜谱`、`高分新菜` 等
- **时令**:按节气推荐时令食材 + 相关菜谱
- ⚠️ 分析文章指出这是**下厨房的槽点**:分类/榜单入口"既深且难找","靠运气才能找到"。**咕嘟应避免此问题,把分类/榜单放显眼位置**。

### 1.4 视频菜谱
**按钮/字段(官方截图实测):**
- 顶部标题:`视频菜谱` / 副标题 `做菜更快更好`
- 视频标题:如 `清甜爽口 番茄玉米排骨汤`
- 播放控件:播放图标、音量图标、进度条(`00:02 / 01:20`)

## 二、搜索

**入口:** 首页顶部搜索框,占位符 `搜索菜谱、课程和食材`
**功能:**
- 联想词、搜索历史
- 结果分 Tab:`菜谱` / `用户` / `作品`(及课程、食材)
- **食材 Top10 菜谱入口**(分析文章建议):搜索某食材时,展示该食材被做过最多的 Top10 菜谱

## 三、菜谱详情 ⭐(高频,咕嘟重点借鉴)

> 这是最核心的页面。综合分析文章描述(官方截图未直接展示该页,字段以分析文章 + 收藏页截图交叉印证为准)。

**页面结构(自上而下):**

### 3.1 头部
- 菜谱封面图(大图)
- **菜名**
- 作者区:作者头像 + 昵称
- 综合评分:如 `8.1 分`(收藏页卡片实测可见)
- 做过人数:如 `529 人做过`(收藏页卡片实测可见,即"人气")
- 右上角:「更多(...省略号)」(举报/分享/不感兴趣等)

### 3.2 用料区(核心借鉴点)
- 分组:`主料` / `辅料`(或按"用料"/"调料")
- 每项字段:**食材名 + 用量**(如 `排骨 500g`)+ **勾选圆圈**(可勾选已备齐)
- 操作按钮:`加入菜篮子` / `丢进菜篮子`(一键把该菜谱全部用料加入菜篮子)
- 用量可按人数换算(部分菜谱支持)

### 3.3 步骤区
- 每步字段:**步骤序号(1/2/3...)** + **步骤图** + **步骤文字说明**
- ⭐ **烹饪模式**(分析文章强建议):一键全屏放大当前步骤、屏幕常亮、**语音控制上一步/下一步/退出**(厨房双手不便操作手机)。**咕嘟可重点借鉴此交互。**

### 3.4 小贴士
- 作者分享的烹饪心得/注意事项(纯文字)

### 3.5 评论区(分析文章建议分区)
- 分区:`评论区`(评价/晒图)+ `提问区`(问答,非作者也能答)
- 消息栏单独提醒"我的提问被回复了"

### 3.6 底部固定操作条
- `加入菜篮子`(用料收集)
- `收藏`(❤️/⭐)
- `做这道菜` / `我做过` / `上传作品`(跟做后晒图)

## 四、菜篮子 ⭐(对应咕嘟「采购清单」,重点借鉴)

> 这是对咕嘟采购清单最有价值的借鉴模块。下厨房的菜篮子 = 从多个菜谱用料汇总成的购物清单。

**功能:**
- 从菜谱详情页「加入菜篮子」一键收集该菜谱全部用料
- 多菜谱用料**汇总**到一个清单
- **合并用料**(如两道菜都要鸡蛋,合并数量)
- 勾选已购(购买后划掉,**分析文章建议:划掉后自动置底,减少漏看**)

**按钮/字段:**
- 顶部:标题 `菜篮子`
- 「更多(...省略号)」→ `合并用料` / `清空菜篮子`
- 清单项:食材名 + 用量 + 勾选框
- ⚠️ **槽点(分析文章核心批评)**:入口太隐蔽——位于「收藏」页右上角小图标,**60%+ 用户找不到**。建议入口前置到首页或"我"页。
- **建议新增**(分析文章):`分享清单`(生成图片发微信,让家人代购)+ `左滑删除` + `加入购物车`(直连生鲜电商)

> 💡 **咕嘟的采购清单已有此场景,应直接学"用料汇总+合并+勾选"的交互逻辑,但把入口做显眼**(咕嘟本身就是 5 Tab 之一,天然优势)。

---

## 五、收藏

**按钮/字段(官方截图实测):**
- 标题区:`收藏最爱` / 副标题 `一键留住好味`(运营文案)
- 顶部按钮:返回 / 分享 / 设置 / 更多 / 编辑
- 菜谱卡片字段:**封面图 + 菜名 + 评分(8.1分) + 做过人数(529人做过) + 作者头像昵称 + 更多(...)**
- 右上角隐藏入口:**菜篮子图标**(隐蔽)

---

## 六、个人主页(我)

**字段/入口(综合分析文章):**
- 头像、昵称、**认证厨师标识**(算法产生,不可自荐)
- 数据:关注数 / 粉丝数 / 获赞数
- 入口列表:
  - `我的菜谱`(我发布的)
  - `我的作品`(我上传的跟做作品)
  - `菜篮子`
  - `我的收藏`
  - `课程订单`(课堂)
  - `订单`(市集购物)
  - `设置`
- ⭐ **会员/积分体系**(分析文章强建议,咕嘟可参考):`厨值`积分 + 等级(Lv.0–Lv.10)+ 等级标识显示在用户名旁。下厨房此体系曾上线又下线,**咕嘟 MVP 暂不建议做,后期可参考**。

## 七、课堂 · 厨Studio(知识付费)

> 不在咕嘟 MVP 范围,仅作记录。

- 形式:直播课 / 录播视频课 / 图文专栏
- 课程详情:课程介绍、讲师、章节、价格、`立即学习`/`加入购物车`
- 会员曾覆盖:`100本电子书 + 50节视频课 + 5个专栏`(已下线)

---

## 八、市集(电商)

> 不在咕嘟 MVP 范围,仅作记录。

- 首页:轮播 Banner + 分类金刚区(`下厨房自营`/`爱尝鲜`/`市集上新`/`市集经典` 等,可个性化匹配)+ 商品瀑布流
- 全部分类:食材/调味品/厨电/厨具/周边
- 商品详情:图、价格、规格、`加入购物车`/`立即购买`、评价
- 购物车 / 订单 / 售后

---

## 九、发布(+FAB)

- 入口:底部中央红色 `+` 按钮
- 选项:`发布菜谱` / `发布作品`
- **创建菜谱表单字段**(分析文章路径图):菜名、封面图、简介、分类标签、用料(主料/辅料,逐项食材名+用量)、步骤(逐步图+文)、小贴士、提交

## 咕嘟对照速查(精简)

| 下厨房模块 | 咕嘟对应 | 关键借鉴点 | 决策 |
|---|---|---|---|
| 菜谱详情(用料+步骤+贴士) | `dish/detail` | 用料勾选、烹饪模式(全屏+语音)、底部操作条 | **P0 借鉴** |
| 菜篮子(用料汇总购物清单) | `shopping` | 多菜谱用料合并、勾选置底、清单分享图 | **P1 借鉴(入口咕嘟已优于下厨房)** |
| 菜谱分类/榜单/时令 | `dish/list` | 分类标签条清晰化、榜单入口前置(避免下厨房的隐蔽槽点) | P1 借鉴 |
| 视频菜谱 | `dish`(图文为主) | 视频菜谱形式(咕嘟暂不做,后期可考虑) | 暂不做 |
| 关注/动态社交流 | `dailylog`(食记) | 弱社交,偏私人记录(咕嘟偏私人食记不做重社交) | 差异化 |
| 个人主页/认证厨师/会员等级 | `profile` | 做过次数徽章;等级体系 MVP 不做 | P2 部分借鉴 |
| 搜索(菜谱/食材/课程) | `dish` 搜索 | 食材 Top10 菜谱入口、搜索联想 | P1 借鉴 |
| 课堂(知识付费) | — | 不做 | — |
| 市集(电商) | — | 不做 | — |
| 发布菜谱/作品 | `dish/create` | 表单字段组织(用料分主辅料、步骤逐步图文) | P2 借鉴 |
