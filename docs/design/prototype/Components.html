图片规范

有图的地方必须有图；菜品用真实照片，食材用插画，人用头像。图片只裁切不拉伸（object-fit: cover）。
比例与圆角
1:1 列表 4:3 卡片 16:9 详情头图（满宽，无圆角）
图片圆角 = 所在卡片圆角 − 4。详情头图满宽，顶部叠返回 / 收藏按钮，底部加深色渐变保证白字可读。
食集拼图 / 头像叠放
+1
食集封面取前 4 道菜 2×2 拼图，不足 4 道时用最多的那道铺满。头像最多叠 3 个，其余显示 +N，带 2px 白描边。
食材插画
放在 secondary 浅底圆角方块里，插画占 70%。「用完」的食材插画去色 + 45% 透明度。按食材品类匹配，没有对应插画时用品类通用图（蔬菜 / 肉 / 调料）。
加载中 / 加载失败
滑 点按重试
加载中为 secondary 底呼吸骨架；失败时显示菜名首字（列表）或图片图标 + 重试（详情）。首字占位只用于失败兜底，不作为常态。
