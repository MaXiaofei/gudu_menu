## 改造设计

### 子项1：后端 sourceMenuId 溯源 + 按食集查（TDD）
- `ShoppingList` 加 `sourceMenuId` 字段
- V38 migration：`ALTER TABLE shopping_list ADD COLUMN source_menu_id BIGINT NULL` + 索引
- `ShoppingService.newList`：menu 来源填 sourceMenuId（plan 来源仍填 sourcePlanId）
- `ShoppingService.getByMenu(menuId)`：查 `source_menu_id=menuId` 最新一条 → 有则 getDetail，无则 null
- `ShoppingController`：`GET /shopping/by-menu/{menuId}` → `R<ShoppingListVO>`（data 可空，前端据此显"生成"按钮）
- 测试：ShoppingServiceTest 加 generate(menu) 验证 sourceMenuId 落库 + getByMenu 命中/未命中

### 子项2：Flutter 食集采购 Tab
- `menu/detail_page.dart` 采购 Tab 换实组件 `_ShoppingTab`：
  - 进入调 `GET /shopping/by-menu/{menuId}`
  - data=null → 「生成采购清单」按钮（POST /shopping/generate{menu, menuId} → 刷新）
  - data≠null → ShoppingItem 列表（三色徽章 + 食材名 + 参考克数 + 勾选 purchased 切换 + 采购量/单位展示）
- 复用 `shopping_page.dart` 的 ShoppingItem 样式（或简化 _ShoppingItemRow）

### 子项3：小程序食集采购 Tab
- `menu/Detail.vue` 采购 Tab：同 Flutter 逻辑（条件渲染 + watch 惰性加载，照备菜 Tab 范式）
- api：`getMenuShopping(menuId)` + 复用 `generateShopping`
