# 食记（做菜日记）实施计划

> **日期**：2026-08-09 ｜ **原型**：`.superpowers/brainstorm/44829-1783002708/content/dailylog.html`（月/年视图 + 按菜汇总 + 筛选 + 单条详情）
> **设计来源**：docs/pantry-shopping-redesign.md §2.1（评价三入口）；docs/menu-review-design.md（统一评价页）
> **注意**：现有 `/dailylog` = 每日营养记录（DailyLog 表），食记是新功能（数据源 cooking_record），不冲突

## 数据源

| 数据 | 来源 |
|---|---|
| 一顿饭（时间轴） | cooking_record 按 menu_id 分组（menu_id null = 历史单菜直做记录） |
| 道菜数 / 做饭天数 / 最常做 | cooking_record 行数 / distinct date(cooked_at) / dish_id 计数 |
| 按菜汇总（次数/最近/★均分） | cooking_record by dish_id + review.star_rating 平均 |
| 年视图 12 月次数 | cooking_record by month(cooked_at) |
| 单条详情用材（用完/用了一些） | **新表 menu_cook_usage**（做菜确认时落库，V45） |
| 评价状态 | review 存在性（menu_id 或 dish_id） |

## 餐次推断规则（纯函数，可单测）

cooked_at 小时：`<10` 早餐 / `10~15` 午餐 / `15~21` 晚餐 / 其余 加餐

## 接口（/food-log）

| 接口 | 说明 |
|---|---|
| `GET /food-log/month?month=YYYY-MM&meal&source&reviewed` | 统计卡（顿饭/道菜/做饭天数/最常）+ 时间轴列表（每组含 menuId/名/时间/道数/人份/菜名/用完X样·用了一些Y样/已评价） |
| `GET /food-log/by-dish?month=&meal=&source=&reviewed` | 按菜汇总（去重菜种数 + 次数/最近时间/★均分） |
| `GET /food-log/year?year=YYYY` | 12 个月做饭次数（0 表示无） |
| `GET /food-log/detail?menuId=` | 单条详情：菜列表（份数/备注）+ 用材（用完/用了一些）+ 已评状态 |
| `POST /menu/{id}/copy` | 再做一次：复制 menu + menu_dish（份数/备注/custom_name；added_by 归新 owner）→ 新食集（ACTIVE） |

## V45 迁移

```sql
CREATE TABLE IF NOT EXISTS menu_cook_usage (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  menu_id BIGINT NOT NULL,
  ingredient_id BIGINT NOT NULL,
  action VARCHAR(16) NOT NULL COMMENT 'used_up 用完 / partial 用了一些',
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  KEY idx_usage_menu (menu_id)
) COMMENT '做菜确认用材记录（食记单条详情）';
```
