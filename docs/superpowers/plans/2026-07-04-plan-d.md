### 子项2：采购回写 pantry

**设计**：
- `PantryService` 加 `stockUpByIngredient(ingredientId, amount, unitId, note)`：换算 grams → insert 新批次（复用 saveWithGrams 模式）
- `ShoppingService.togglePurchased` 增强（仅 0→1 时回写）：
  - purchaseAmount + purchaseUnitId 非空 → `unitConvert.toGramsFor` 换算 grams
  - 兜底：purchaseAmount/unitId null → 用 `referenceGrams`（参考克数）
  - 都 null 或 ingredientId null → 跳过回写（仅标 purchased）
  - 1→0 **不反向扣减**（库存已消耗，避免复杂/误扣）
- TDD：`PantryServiceTest.stockUpByIngredient` + `ShoppingServiceTest.togglePurchased_回写pantry`

**闭环验证**（staging）：
1. 生成采购清单（menu 1）→ 填某项 purchaseAmount+unitId（或留空用 referenceGrams）
2. PUT /shopping/item/{id}/purchased（勾选）
3. GET /pantry?ingredientId=X → grams 增加
4. 前端 pantry 列表刷新看到新批次
