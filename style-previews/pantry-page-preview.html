库存管理：自动（做菜按用料扣）+ 手动（盘点纠正 / 手动添加）。
盘点入口：点食材行进入详情页，在加减盘改差额，保存返回库存页。盘点只纠偏、不带来源标签。
手动添加入口：右下「添加」，产生带「手动」标签的新记录（别人送 / 赠品 / 旧库存补登）。
盘点 vs 手动添加：盘点只纠偏（改已有项的差额，不产生来源标签）；手动添加新增条目（带「手动」来源标签）。
每笔变动有来源：做菜 / 采购入库 / 盘点 / 手动添加，方便对账。
